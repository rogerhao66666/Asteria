# Asteria Reference Asset Pack — Alpha

These files are original Asteria reference/development art created specifically
for this project. They are not copied from RPG Maker, Octopath Traveler,
ASTLIBRA, or any commercial game.

## Included
- `asteria_environment_atlas_1x.png` — 16×16 engine tiles
- `asteria_environment_atlas.png` — 3× inspection copy
- `asteria_hero_sheet_1x.png` — 16×24 hero, 4 directions × 4 walk frames
- `asteria_hero_sheet.png` — 3× inspection copy
- `asteria_props_1x.png` — tree/lamp/bench/sign/chest/barrel concepts
- `asteria_props.png` — 3× inspection copy

## Art direction
Small detailed pixel characters + dense pixel environments + modern renderer
lighting/VFX. This alpha pack establishes the visual language and validates the
exact import/runtime path before a larger polished pack is produced.
