# Batch 86 Battle Scheduler Demo

Run `python demos/phase7b_batch86/verify_battle_scheduler_demo.py` for deterministic verification.
Run `python demos/phase7b_batch86/run_battle_test_harness.py` for the pygame developer battle sandbox.

The harness uses the continuous scheduler: high-speed combatants may receive multiple turns before slower combatants. It is intentionally developer UI, not final battle presentation.
