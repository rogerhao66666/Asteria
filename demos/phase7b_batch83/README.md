# Phase 7B Batch 83 demo
Run `PYTHONPATH=src python demos/phase7b_batch83/verify_battle_states_demo.py` from the repository root.
The demo verifies generic battle-state admission, stat/tag-driven resistance and immunity, source provenance, ability blocking, lifecycle ticking, periodic effects, trigger-driven removal, Doom-like expiry effects, and snapshot restore. Poison/Stun/Silence/Sleep/Doom are demo content, not engine enums.
