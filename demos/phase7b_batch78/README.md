# Phase 7B Batch 78 Demo

This demo uses the same canonical Asteria Project and RPG save format as the engine.
It demonstrates flexible equipment capacity, simultaneous multi-weapon loadouts, and generic capability-driven equipment eligibility.

Run:

```bash
PYTHONPATH=src python demos/phase7b_batch78/verify_equipment_capability_demo.py
```

The project itself remains loadable/playable through the existing Asteria Editor/runtime. RPG interaction GUI is intentionally deferred until the Phase 7B backend contract is stable.
