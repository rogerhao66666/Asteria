# Phase 7B Batch 85 demos

`verify_battle_lifecycle_demo.py` is a deterministic backend verification for objectives and escape.

`run_battle_test_harness.py` is the real-window developer sandbox. It extends Batch 84 with combatant lifecycle actions: KO/incapacitate, revival, summon, transform/revert, objectives, and escape. It is intentionally not final battle art or final RPG GUI.

Run from the repository root with `PYTHONPATH=src python demos/phase7b_batch85/verify_battle_lifecycle_demo.py` or `PYTHONPATH=src python demos/phase7b_batch85/run_battle_test_harness.py`.
