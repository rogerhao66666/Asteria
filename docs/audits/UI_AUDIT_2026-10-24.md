# 遊戲內選單畫面稽核（2026-10-24）

**範圍：** Full Verification demo 的每一個選單畫面在遊戲裡長什麼樣子，以及作者在編輯器裡能改到什麼程度。

**方法：**
- `scripts/ui_tour_live_check.py` 在 Cocoa 真實視窗、靜音下，把每個畫面依遊戲的方式打開，英文和中文各截一張，共 56 張。
- 存檔先放進配方、可接的任務、兩隻寵物和兩行對話紀錄，畫面才不會是空的。
- 編輯器在「演出 ▸ 選單畫面」和「演出 ▸ 戰鬥畫面」各截一張做對照。
- 截圖都在 `docs/audits/evidence/ui_tour/`，總覽圖是 `sheet_zh_*.png`、`sheet_en_*.png`。

## 一、有哪些畫面

| 畫面 | 截圖 | 編輯器能改什麼 |
|---|---|---|
| 標題、暫停、設定、存讀檔、遊戲結束 | `*_title`、`*_pause`、`*_settings`、`*_save_slots`、`*_game_over` | 暫停選單可加自訂項目；版面、顏色、字型都不能改 |
| 狀態選單四頁（狀態、道具、裝備、技能） | `*_status*` | 「選單畫面」可改標籤、區塊順序、屬性順序、每頁筆數 |
| 背包（格子） | `*_bag` | 同上，只有標籤與數量 |
| 技能樹 | `*_skill_tree` | 樹的內容可改；畫面樣式不能改 |
| 角色養成選單、工坊（精煉、鑲嵌、屬性點） | `*_build`、`*_workshop` | 都不能改，是測試用的畫面 |
| 製作 | `*_crafting` | 配方可改；畫面樣式不能改 |
| 商店（買、賣） | `*_shop_buy`、`*_shop_sell` | 商品與價格可改；畫面樣式不能改 |
| 任務紀錄、寵物、成就、怪物圖鑑 | `*_quests`、`*_pets`、`*_achievements`、`*_bestiary` | 資料可改；畫面樣式不能改 |
| 訊息紀錄、音樂室、製作人員、技能欄 | `*_backlog`、`*_music`、`*_credits`、`*_ability_slots` | 製作人員頁的文字可改；樣式不能改 |
| 戰鬥 | `*_battle` | 幾乎全部可改：版面、外框、位置、角色圖、動畫、特效 |

**所有選單共用的只有一張外框圖**（戰鬥介面主題的 `host:panel` 九宮格）。除此之外，位置、大小、顏色、字級、圖示、背景都寫死在程式裡。

## 二、不存在的系統

- **轉蛋**：沒有卡池、機率、保底、抽卡動畫，也沒有畫面。
- **招募**：只有世界互動的「recruit」動作；沒有招募所、候選人清單、費用、招募畫面。
- **任務板／任務卡**：只有任務紀錄清單；沒有可以挑選、接下的任務卡。
- **煉金**：製作系統可以用工作台區分，但沒有獨立的煉金畫面；demo 的配方都要在指定工作台，從選單打開時是空的。

## 三、看起來的問題

- **大多數選單只是灰底文字表格。** 沒有角色立繪、沒有道具說明欄、沒有數值比較；只有背包有格子和說明框。
- **工坊和養成選單是測試畫面。** 標題寫「角色／養成驗收選單」，按鍵是 R、S、X、A、1–8。
- **鑲嵌不能選。** 工坊按 S 會把背包裡第一顆合適的寶石塞進第一個空孔。玩家不能選哪一顆寶石、哪張卡片、哪個孔，也看不到裝上後數值怎麼變。惡魔之戒有七個孔（卡片、寶石、護符），一樣只能這樣用。
- **精煉資訊不完整。** 只寫成功率和金幣，看不到需要的材料、失敗會怎樣。
