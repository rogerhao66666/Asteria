# 選單畫面全面計畫 U1–U6（2026-10-24，待核准）

依據：`docs/audits/UI_AUDIT_2026-10-24.md`（56 張真實視窗截圖）與使用者的要求：

- 每個畫面都要能在編輯器自由設計，遊戲內呈現得好看。
- 作者可以用自己畫的圖、字型、音效，也可以用引擎附的預設素材。
- free_assets 裡能用的素材都要用上。

## 原則

1. **畫面的「長相」全部是資料。** 版面、外框、背景、字型、顏色、圖示、音效都存在專案裡，在編輯器改。引擎只負責畫面的邏輯，例如按下確定會買東西、會鑲上寶石。
2. **每一個放圖的欄位都接受任何專案素材。** 作者按「匯入」放進自己的 PNG、TTF、OGG 就能用；九宮格外框可以在編輯器拉四條線設定。
3. **預設版面和現在一模一樣。** 沒有設定版面的專案，畫面逐像素不變（照 D60 的做法驗證）。
4. **不寫死任何玩法。** 部位、工作台、卡池、任務板、招募所都由作者定義，demo 只是範例。
5. **Demo 用 free_assets 的 CC0 素材做出好看的預設。** 作者可以整套換掉。

## U1：中文畫面裡的英文和 id（小批）

**修正：**
- 背包說明框的數值名稱與部位（`Defense`、`Lightning resist`、`Armor`）改走數值與部位的翻譯。
- 技能樹標題列：`AP`、`JP.ARCHMAGE`、`SKILL_POINTS` 改顯示點數的名稱；`Magic Attack +5` 等加成走數值翻譯。
- 任務目標顯示目標的名稱（新增 `data.quest.<id>.objective.<n>`），沒有名稱時用目標對象的名稱，例如「侍僧 0/6」。
- 寵物數值改走數值翻譯。
- 養成選單、工坊：角色與職業用名稱；孔用 `SocketDefinition` 的名稱（新增選填 `label`），沒有就寫「孔 1」。
- 編輯器「選單畫面」的屬性順序標籤顯示數值名稱，id 放在提示裡。

**防止再發生：**
- 新測試把每個畫面在中文下畫一次（無視窗），收集畫出的文字。
- 只要出現資料庫裡的 id，或出現已有中文翻譯的英文詞，測試就失敗。

**證據：** 導覽腳本中英文各重跑一次，附修正前後對照。

## U2：選單版面系統（核心，分三段）

### U2a 引擎

**資料：** 演出庫新增 `menu_layouts`，每個畫面一份，畫面清單是固定的 id：
- 標題、暫停、設定、存讀檔、遊戲結束。
- 狀態、道具、裝備、技能、背包、技能樹。
- 商店、製作、強化（取代工坊）、任務紀錄、任務板、招募、轉蛋。
- 寵物、成就、怪物圖鑑、訊息紀錄、音樂室、製作人員、技能欄、穿裝提示、地圖提示列。

**一份版面包含：**
- 設計尺寸，預設 1280×720，依視窗等比縮放。
- 背景：顏色、圖片，或把地圖畫面調暗。
- 一組元件，每個元件有位置、錨點和圖層順序。

**元件種類：**

| 種類 | 用途 |
|---|---|
| 面板 | 九宮格圖、單張圖或純色 |
| 圖片 | 任意素材，可拉伸、置中、平鋪 |
| 文字 | 固定文字（翻譯鍵）或綁定欄位，例如「金幣」「店名」 |
| 清單 | 綁定資料來源；每列的樣板含圖示、名稱、各欄、選取時外框；可捲動 |
| 格子 | 欄數、列數、格子大小、空格圖、選取框圖 |
| 部位欄（紙娃娃） | 每個部位的位置、空格剪影圖；部位由作者在資料庫定義 |
| 說明框 | 綁定目前選取的東西：大圖示、名稱（依稀有度上色）、說明、數值、與身上裝備的比較 |
| 量條 | 綁定 HP、MP、經驗、耐久等 |
| 分頁 | 例如買／賣、精煉／鑲嵌／卡片 |
| 頭像 | 角色、商人、招募候選人 |
| 按鍵提示列 | 文字依實際按鍵設定產生 |

**資料來源：** 每個畫面提供固定的資料來源與欄位，例如商店有 `entries`、`wallet`、`selected`、`shop.name`、`keeper.portrait`。元件只綁這些名字，所以換版面不會影響邏輯。

**主題：** 專案層級的選單主題，各畫面共用：
- 字型：可分拉丁字和中日韓字；中文缺字時改用內建的 Noto Sans TC。
- 各種文字角色的字級與顏色、稀有度顏色。
- 游標圖、選取列外框。
- 移動、確定、取消、購買、失敗的音效。
- 現有 `BattleUiTheme.panel_skins` 繼續有效。

**預設：** 引擎內建的預設版面重現現在的畫面。未設定的專案在 39 個畫面上逐像素比對。

### U2b 編輯器「演出 ▸ 選單畫面」

- **左邊：** 畫面清單；有自訂的畫面加標記，沒有的就是用預設。
- **中間：** 所見即所得的畫布。用遊戲真正的繪製程式加範例資料畫出來；元件可以拖曳、縮放、對齊格線、多選。
- **右邊：** 元件屬性。
  - 種類、位置、錨點。
  - 素材：選圖、匯入自己的 PNG、九宮格四條線的拉桿與預覽。
  - 字型與顏色。
  - 綁定的欄位（下拉選單，只列這個畫面有的）。
- **工具列：** 從另一個畫面複製版面、套用整套範本、還原成預設、在遊戲裡預覽（直接打開那個畫面）。
- 現有六種畫面設定（標籤、順序、每頁筆數）併進同一頁。
- 全部可以 Ctrl+Z 復原；所有新文字都有中文。

### U2c 把每個畫面換成用版面畫

- 狀態四頁、背包、商店、任務紀錄、寵物、成就、圖鑑、訊息紀錄、音樂室、製作人員、技能欄、標題、暫停、設定、存讀檔、遊戲結束、穿裝提示，逐一改成依版面繪製。
- 每換一個畫面，就驗證預設版面逐像素不變。

## U3：裝備與強化畫面

**裝備畫面（紙娃娃）：**
- 部位欄、背包格、說明框加數值比較。
- 選部位後只列能穿的裝備；按確定穿上，或卸下。
- 套裝效果與耐久也顯示出來。

**強化畫面**取代現在的工坊測試畫面，分四頁：
- **精煉：** 列出需要的材料（已有／需要，不足標紅）、金幣、成功率、失敗會怎樣（掉級、損毀、保護道具），並預覽 +1 後的數值。
- **鑲嵌：** 先選裝備，再選孔（顯示接受哪種標籤），再從背包挑合適的寶石或寶珠。裝上前先看數值變化；取下時列出代價與是否會毀掉。
- **卡片：** 與鑲嵌相同的流程，篩選卡片；顯示卡片效果與套裝加成。
- **成長／進化：** 裝備成長的計數與下一階段。

其他：
- 舊的養成驗收選單改成「開發者選項」才會出現。
- 惡魔之戒的七個孔可以一個一個選。

**Demo：** 裝備畫面預設用 Lucifer UI 的 Inventory 紙娃娃；強化畫面用 Lucifer 的面板和按鈕。

## U4：製作與煉金畫面

- **資料：** 新增「工作台」種類：名稱、圖示、版面、配方分類、音效、成功動畫。煉金、鍛造、料理都是作者自己建的工作台。
- **畫面：**
  - 依分類分頁；配方清單附成品圖示。
  - 列出需要和已有的材料；可選製作數量。
  - 顯示品質或成功率；未發現的配方顯示「？？？」。
  - 分解頁使用現有的分解配方。
- **Demo：** 爐心鎮加一張煉金台（藥師瑟拉旁）和一座鍛造爐（武器匠布蘭旁）；G2 的材料拿來當配方原料。

## U5：新系統（全部是資料，在編輯器編）

### 任務板與任務卡
- **任務新增卡片欄位：** 卡片圖、階級、分類、報酬預覽、可重複、期限。
- **新種類「任務板」：** 列出哪些任務、接取條件、刷新規則、同時可接上限、版面。
- 新的事件指令 `OPEN_QUEST_BOARD`。
- **畫面：** 任務卡排成一排或格子；選中後翻開顯示詳細內容、接取或回報。

### 招募
- **新種類「招募所」：** 候選人（角色，或角色範本加隨機數值）、費用、條件、隊伍上限、能否解僱、版面。
- 新的事件指令 `OPEN_RECRUIT`。
- **畫面：** 候選人頭像、職業、數值預覽、費用、招募確認。
- **Demo：** 冒險者公會現在由腳本雇用三位同伴，改成走招募畫面。

### 轉蛋
- **新種類「卡池」：**
  - 名稱、橫幅圖、貨幣與單抽／十連價格、獎池。
  - 獎池可以是道具、裝備、角色、寵物，各有權重與稀有度。
  - 機率表、保底（硬保底和軟保底）、十連保證稀有度、限定加倍、重複時轉換成其他獎勵、抽卡紀錄。
- **演出可以編輯：** 寶箱出現 → 搖晃 → 依最高稀有度開出不同光芒 → 結果格子；每一步的圖、音效、時間都可以改。
- 新的事件指令 `OPEN_GACHA`。
- 機率表頁面預設一定會顯示，作者不能關掉。
- 測試用固定的亂數種子。
- **Demo：** 新貨幣「星石」，從任務與成就取得。卡池用寶箱包的普通、稀有、神話寶箱。

### 編輯器
- 遊戲系統頁新增工作台、任務板、招募所、卡池四種資料。
- 每種都有預覽；卡池另有「模擬一萬抽」，顯示實際分佈與保底觸發次數。

## 需要你決定的事

1. **Demo 的裝備部位。** Lucifer 紙娃娃畫了頭、身體、手、腳、項鍊、武器、副手；demo 現在只有武器、防具、飾品、形態。
   - **建議：** demo 加上頭、手、腳、副手四個部位，各補幾件裝備（用 7Soul 圖示）。這會改變 D61「只保留兩個防具部位」的決定。
   - **另一個選項：** 部位維持不變，紙娃娃上沒用到的格子隱藏。
2. **寶箱包放哪裡。**
   - **建議：** 原檔留在 Downloads；demo 只放縮到 256 像素的副本（約 2 MB），CREDITS 註明來源。
   - **另一個選項：** 原檔整包放進 asset_library（+88 MB）。
3. **轉蛋貨幣。** 建議 demo 新增「星石」，從任務與成就取得；另一個選項是直接用金幣。
4. **字型。** 建議英文用 PixelRpgFont，中文用 Noto Sans TC；另一個選項是全部用 Noto。
5. **養成驗收選單。** 建議改成開發者選項才出現；另一個選項是刪掉。
6. **順序。** 建議 U1 → U2a → U2b → U2c → U3 → U4 → U5 → U6，每段結束都交截圖和報告給你看。

## 規模與風險

- **最大的是 U2。** 它會改到幾乎所有選單的繪製程式。每換一個畫面都要做逐像素比對，避免現有專案變樣。
- **U5 是三個全新系統，** 每個都要有資料、畫面、編輯器、事件指令、存檔欄位與翻譯。
- **共用檔案。** 其他 session 正在改戰鬥與生物系統，共用的檔案（built_in_text、決策紀錄、手冊）提交時照 D61 的方式只挑這批的 hunk。
