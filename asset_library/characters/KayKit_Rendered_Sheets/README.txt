KayKit Rendered Sheets

2D sprite sheets photographed with Blender from the KayKit Adventurers 2.0 characters and
props and the KayKit Character Animations 1.1 clips (both by Kay Lousberg,
www.kaylousberg.com, Creative Commons Zero / CC0 1.0 - see the License.txt of each pack
beside this folder). The renders are derived works of CC0 material and are offered under
the same terms: CC0 1.0, free for personal and commercial use, no attribution required.

Built by scripts/build_kaykit_art.py (--render needs Blender; a demo build only reads
these files). <key>_battle.png + .json: every battle clip on one grid, drawn with
scaling "smooth"; <key>_field.png + .json: the 3 x 4 walking sheet (down, left, right, up).
No generative AI was used.
